# Pull requests

Open a pull request only when the developer asks for one.

`CONTRIBUTING.md#commits-and-pull-requests` owns the rules: the template and
its checkboxes, what counts as verification evidence, the
`scripts/pr-policy.ts` check, screenshot uploads, attribution, and how to
handle review bots. Read that section before writing the description.
