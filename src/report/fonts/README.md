# Report fonts

Decant embeds these WOFF2 files as data URLs so exported reports remain
self-contained and make no runtime network requests.

- IBM Plex Sans Regular and Semibold, Latin 1 split
- IBM Plex Mono Regular, Latin 1 split
- Source Serif 4 Semibold

The IBM files come from the official
[`IBM/plex`](https://github.com/IBM/plex) repository. Source Serif comes from
the official [`adobe-fonts/source-serif`](https://github.com/adobe-fonts/source-serif)
release branch. Both families are distributed under the SIL Open Font License
1.1; the unmodified upstream license texts are included beside the fonts.
